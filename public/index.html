Projects

  • ValueJet

    ValueJet is a flight booking website focused on Nigerian local flights, offering services for booking flights, online check-in, and managing bookings. Key features include a 7kg hand luggage policy, airport lounge access, and tiered packages (ValueLite, ValuePlus, ValuePremium) with varying baggage allowances and priority services. The site supports routes to Abuja, Lagos, Port Harcourt, and Jos, and includes a mobile app for baggage and check-in options. Built with React.

  • Touchdown Travels

    Touchdown Travels is a website for booking cheap flights, with the purpose of helping users find and book flights for their adventures. Key features include a flight search form allowing users to select one-way trips, specify departure and return dates, choose cities for "From" and "To," indicate the number of passengers, and select the class (e.g., Economy). It also offers options to browse flights by region, such as African, European, Asian, and North American flights, and guarantees the best price. Built with React.

  • Ajala

    Ajala.ng is a travel booking website focused on helping users plan trips by offering flight search and booking services, along with holiday deals and travel payment options. Key features include a flight search tool for finding affordable flights from Nigeria to various destinations, displayed top deals for routes like Houston, London, and Kigali, holiday packages such as group trips to Qatar, a newsletter signup for travel ideas, and a PayEasy plan for flexible payments with a 25% deposit. It also provides FAQs on booking processes, multi-city flights, and child travel. Built with React.
